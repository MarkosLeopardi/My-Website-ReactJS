# My Website – ReactJS Practice Project

## Overview

This project is a **personal website rebuilt in ReactJS** as a way to practice and better understand **React fundamentals**.

The original version of the website was first created using **HTML/CSS** as part of a university assignment, and this project was my attempt to **rebuild the same concept using React**, in order to learn how to structure a front-end application with components.

---

## Live Demo

[View the website here](https://users.iee.ihu.gr/~it154484/my_site_react/)

---

## Purpose

The main purpose of this project was to:

- Practice **ReactJS basics**
- Understand how to break a page into **reusable components**
- Recreate an already existing website using a more modern front-end approach
- Gain hands-on experience by converting a static page into a React-based project

---

## Tech Stack

- **ReactJS**
- **JavaScript**
- **HTML5**
- **CSS3**

---

## Features

- Multi-section personal website structure
- React component-based implementation
- Static content sections for personal presentation
- Foundation for future portfolio expansion

---

## What I Practiced

Through this project, I focused on:

- Learning how React applications are structured
- Converting a static HTML page into a React project
- Separating UI into components instead of keeping everything in one file
- Understanding the difference between a static webpage and a component-based front-end application
